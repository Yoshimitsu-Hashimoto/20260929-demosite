### 確認に使うデータ

公開ページの確認は、**管理画面にログインしていない状態**で行います。ログインした管理者には下書きの実績の詳細ページも表示されるためです。

| 確認したいこと | 使うデータ |
|---|---|
| 公開済みの実績だけが表示される | 「喫茶 ひだまり 様」（下書き）が一覧・トップページに出ず、詳細URL（`/works/hidamari-draft/`）はページが見つからない（404） |
| 業種で絞り込める | 各業種3件ずつ。業種ごとのタイトルは上の表のとおり |
| 絞り込み結果が0件のときの表示 | 業種「医療」 |
| 任意項目「制作年」が未入力のときの表示 | 「さくら学習室 様」（`/works/sakura-gakushu/`） |

## お問い合わせフォームの送信先

フォームから送信した内容は、管理者メールアドレス `admin@example.test` 宛てのメールとして確認用メールボックス（Mailpit、http://localhost:8091/ ）に届きます。外部には送信されません。

テストで入力するメールアドレスには `@example.test` など、実在しないドメインを使ってください。
