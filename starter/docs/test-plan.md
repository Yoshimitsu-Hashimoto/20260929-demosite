# テスト計画

[サイト仕様書](spec.md) と [テストデータ](test-data.md) をもとにしたテスト計画です。合否は仕様書の受け入れ条件で判断します。

## 1. 前提

| 項目 | 内容 |
|---|---|
| サイトURL | http://localhost:8090/ |
| 確認用メールボックス | http://localhost:8091/ （Mailpit。API：http://localhost:8091/api/v1/messages ） |
| 確認する状態 | 管理画面にログインしていない訪問者（ログイン中だと下書きの実績も表示されるため） |
| テストデータ | [test-data.md](test-data.md) のとおり投入済み（公開済み9件・下書き1件、業種4つのうち「医療」は0件） |
| お問い合わせのテスト前の準備 | テストごとに確認用メールボックスを空にする |
| テストで使うメールアドレス | `@example.test` など実在しないドメインだけを使う |

- 仕様に書かれていない動作を見つけた場合は、合否を付けず「仕様の確認事項」として記録する。
- 対象外（仕様書 1. 対象外）：会社案内・プライバシーポリシー・お知らせ・ヘッダーとフッターの内容、管理画面の操作、デザインの細部、性能、本番環境へのメール送信。

### 種別

| 種別 | 意味 |
|---|---|
| 正常 | 想定どおりの使い方で、期待どおりに動くか |
| 異常 | 誤った入力や、見えてはいけないものが見えないか |
| 境界 | 0件、未入力、未公開、空の値、存在しない値など、条件の境目 |

| お名前 | 山田 太郎 |

| プライバシーポリシーへの同意 | チェックあり |
